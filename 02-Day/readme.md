# Day 2 – JavaScript Objects 🚀

Today I learned and practiced **JavaScript Objects**.

### 📚 Topics Covered

* Object key-value structure
* Accessing object properties
* Nested / deep-structure objects
* `for...in` loop
* Object destructuring
* Spread operator (`...`)
* `Object.assign()`
* Dynamic keys using bracket notation
* JSON cloning using `JSON.parse()` and `JSON.stringify()`
* Destructuring property names with hyphens
